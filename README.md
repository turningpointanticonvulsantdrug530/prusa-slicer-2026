## 🧰 What You Can Do with PrusaSlicer

PrusaSlicer takes your 3D model files (like STL or OBJ) and slices them into layers. It generates G-code that your printer understands. You can adjust settings like layer height, infill, supports, and print speed. The software is designed for beginners and experts alike. It works with many FDM printers, including Prusa models.
